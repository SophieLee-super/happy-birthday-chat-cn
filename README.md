# 生日快乐，在一场聊天里 🎂

一个小小的互动生日网站——送给朋友的"程序员的浪漫"。
整个网站只有一个 `index.html`，没有构建步骤，没有任何依赖，打开就能玩。

## 它有什么

1. **一场模拟聊天**——消息在手机样式的聊天框里一条一条出现，带打字中的小圆点，还有可以点选的回复（一个小小的分支剧本，包括一句会跟着生日真实星期走的"疯狂星期四"玩笑）。
2. **你的生日有什么特别**——一屏一句平平的话，点一下看下一句：你出生那天是星期几、谁和你同一天生日、这一天历史上发生过什么、你的生辰花、你来到这个世界多少天了、你几岁了。
3. **气球、彩灯和蛋糕**——气球从屏幕底部缓缓升起，还有一根可以点灭许愿的蜡烛。
4. **一封信**——在最后，一个字一个字打出来。

## 一分钟改成你自己的

所有个人信息都在 `index.html` 里脚本最上方的一个 `CONFIG` 区块里：

- 把 `birthDate` 改成你朋友的生日（`YYYY-MM-DD`）——星期玩笑和整个"特别的生日"部分都会自动重新生成。
- 或者直接分享带日期的链接：`index.html?date=2000-01-01`——链接里的日期优先，不用改任何代码。
- 聊天台词、点选回复和信的内容，都在同一个 `CONFIG` 区块里，逐字改成你想说的话。
- 同一天生日的名人 / 历史事件在一张按 `MM-DD` 索引的小表里——如果你的日期还不在表里，把那两屏自动跳过，不会瞎编。

## 运行 / 免费上线

- 本地：用任何浏览器打开 `index.html` 即可。
- 在线：开启 **GitHub Pages**（Settings → Pages → Deploy from branch `main`，文件夹选 `/ (root)`），把得到的链接发给朋友。想换生日，就在链接后面加 `?date=YYYY-MM-DD`。
